# Airbnb ETL Pipeline

Developed an end-to-end ETL pipeline to transform raw Airbnb data into analytics-ready datasets, enabling data-driven business decision-making.
- **Data Ingestion:** Uploaded and stored raw Airbnb datasets in an Amazon S3 bucket.
- **Data Processing:** Processed and transformed the data using Python and SQL within an Amazon SageMaker Notebook instance.
- **Data Storage:** Stored the cleaned and transformed datasets in Amazon S3.
- **Data Cataloging:** Configured an AWS Glue Crawler to automatically discover and catalog the processed datasets.
- **Data Analysis:** Made the final datasets accessible through Amazon Athena for SQL-based querying and analysis.

**AWS Services Used:** Amazon S3, Amazon SageMaker AI, AWS Glue Crawler, Amazon Athena
